# Прототип «Киберурок — срез готовности школ»

Браузерный frontend-прототип для демонстрации Министерству образования. Прототип собран на основе 186 ответов директоров из исходного XLSX-файла.

## Что внутри

- экран руководителя с ключевыми метриками и проблемными блоками;
- интерактивный поиск школы, фильтры по муниципалитету и уровню риска;
- матрица школ с цветовой индикацией проблемных зон;
- карточка выбранной школы с реальным ответом директора и проблемными точками;
- три части рекомендации по каждой проблеме: что сделать школе, что требуется от платформы/организаторов и как проверить результат;
- список приоритетных школ;
- отдельный экран «План действий» по повторяющимся проблемам.

Все рекомендации в интерфейсе помечены как **аналитические предложения**, а не как официальные регламенты.

## Запуск и просмотр

1. Откройте терминал в этой папке.
2. Запустите любой простой локальный сервер, например:

   ```bash
   python3 -m http.server 4173
   ```

3. Откройте в браузере: http://localhost:4173

Можно также открыть `index.html` напрямую, но для корректной работы в некоторых браузерах предпочтителен локальный сервер.

## Изменённые файлы

- `prototype/index.html` — структура интерфейса и экраны.
- `prototype/styles.css` — визуальная система, адаптивная вёрстка и состояния.
- `prototype/app.js` — фильтры, расчёт индекса риска, матрица, карточка школы и рекомендации.
- `prototype/data.js` — извлечённые и нормализованные данные 186 ответов директоров.
- `prototype/README.md` — запуск и описание прототипа.

Исходный XLSX не изменялся. Файлы за пределами `prototype/` не изменялись.
