# Кибермишка: тренировка по кибербезопасности

Браузерная учебная новелла для проекта «Киберурок» (5–9 классы). Работает без сервера и без сбора персональных данных.

## Запуск

Откройте `index.html` в современном браузере или разместите всю папку `cyberbear-game` на сайте школы / «Киберурока».

## Миссии (версия 2.1)

1. **Неизвестный номер** — «мама» с чужого номера, карта, СМС-код, давление.
2. **Выигрыш в конкурсе** — фейковый приз, ссылка, «оплата доставки».
3. **Поддержка игры** — «модератор», пароль, фишинговая ссылка.
4. **Сообщение от «друга»** — взломанный аккаунт, срочный перевод, код.

В каждой миссии — ветвящийся диалог. Победа засчитывается при безопасном завершении разговора.

## Структура

```
cyberbear-game/
  index.html
  app.js           # движок чата и UI
  scenarios.js     # тексты и ветки миссий
  styles.css
  assets/cyberbear.png
```

## Правила безопасности контента

- Нет полей для ввода настоящих персональных или платёжных данных.
- Рискованные ответы учебные: диалог продолжается, Кибермишка объясняет уловку.
- Можно сменить миссию в любой момент кнопкой «К миссиям».
